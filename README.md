# NexCart – Premium React eCommerce Template

NexCart is a modern, high-performance React eCommerce template designed for selling physical and digital products. Built with scalability, performance, and premium UI/UX in mind, it is perfect for marketplaces like ThemeForest or personal projects.

---

## 🚀 Features

- ⚡ Built with React + Tailwind CSS
- 🛍️ Full eCommerce UI (Shop, Product, Cart)
- 🔍 Product filtering (category, search, tags)
- 🧠 Smart product data structure (variants, sizes, colors)
- 🖼️ Image gallery with hover zoom
- 🎯 Product variants (color + size logic)
- 🛒 Cart system (context-based)
- 📱 Fully responsive (mobile-first)
- 🎨 Premium UI (glassmorphism, gradients, modern layout)
- 🔗 SEO-friendly routing using slugs
- ⭐ Product ratings & reviews UI
- 📦 Stock & inventory ready
- ❤️ Wishlist-ready structure (extendable)
